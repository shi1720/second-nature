## Description

A film with somewhere to go. A creative process worth repeating.

SECOND NATURE Studio turns one carefully directed visual idea into a repeatable Blender production workflow. Explore the original film, choose a drop and enamel palette, set consistent soil detail, and keep the production's settings with its outputs.

Try the studio:
https://second-nature-studio.web.app

Explore the source and testing record:
https://github.com/shi1720/second-nature

This demonstration follows the real app: guest or email access, palette selection, a saved production, actual cloud progress, cancellation and resume, and the finished film's playback and downloads. Rendering takes much longer than this 80-second edit; interface captures and production evidence are edited for clarity. The video does not imply that a full render finishes in 80 seconds.

The featured original is a complete 24-second 1080p film rendered locally. Cloud variants cover the same full story at 540p. A full cloud render can take around 80 minutes on the current CPU worker and continues when the page is closed. Shared daily limits apply. Generated exports and frames are subject to seven-day expiry, so download files you want to keep.

Created by Shivam Gupta with AI assistance from OpenAI Codex. The film's geometry, materials and mathematically synthesized soundtrack were created for this project. Space Grotesk is used under SIL OFL 1.1. The demonstration narrator is a stock synthetic Kokoro af_heart voice, not a clone or recording of Shivam. Source includes the script, caption timings and voice provenance.

Blender, Python and FFmpeg power production. Firebase Hosting and Authentication serve the app and workspaces; Cloud Run workers and private Cloud Storage run and retain the productions. The controls vary an authored film system rather than generating arbitrary stories from a prompt.
