# Video publication copy

## Title

SECOND NATURE - Make Every Second Grow | Blender Speed Contest 2026

## Description

One drop. A world in motion. A reason to arrive.

SECOND NATURE is a 24-second Blender film about purposeful speed. A luminous amber drop races through precision gates and a vertical loop to reach a dry seed. The machine gives way to a held breath, a fall, and a flower.

Entrant and project lead: Shivam Gupta.

Created for the RenderJuice Blender Animation & Programmatic Rendering Contest 2026. Blender is the primary creation tool. The scene, geometry, materials, motion paths, camera edit and staggered petal unfolding are constructed with Blender Python. Motion is baked into keyframes. The soundtrack is original mathematical synthesis with no recorded samples.

Source, editable scene and production notes:
https://github.com/shi1720/second-nature

AI and asset disclosure: OpenAI Codex assisted with concept development, code, production automation, documentation and review. Geometry, materials and synthesized audio were generated for this project. Typography uses Space Grotesk under SIL OFL 1.1. Tools include Blender, Python, FFmpeg, NumPy and Pillow. No stock models, image textures, recorded music or generative video were used. This is scripted keyframe animation, not a physical simulation. Rendering is local; no RenderJuice cloud rendering or sponsor endorsement is claimed.

Make every second grow.
